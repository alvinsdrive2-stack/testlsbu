# GAPENSI Website Design Taste

## Core Direction

**Modern Indonesian Institutional × Infrastructure Editorial**

The website should feel:

* authoritative
* sophisticated
* modern
* architectural
* professional
* spacious
* established
* distinctly Indonesian

The visual impression should be closer to a **premium infrastructure institution / architecture organization / national professional association** than a generic corporate or government website.

---

## 1. Overall Aesthetic

### Desired

**Calm. Strong. Editorial. Architectural. Institutional.**

The design should communicate confidence through composition rather than decoration.

Use:

* large typography
* strong grids
* generous whitespace
* bold photography
* structured layouts
* subtle borders
* restrained colors
* asymmetric editorial compositions
* strong visual hierarchy

Avoid:

* excessive rounded cards
* excessive shadows
* gradients everywhere
* overly colorful UI
* generic SaaS layouts
* dashboard aesthetics
* decorative illustrations
* excessive icons
* cramped layouts

---

# 2. Visual Mood

Think:

> **Concrete + steel + architecture + Indonesia + institutional authority**

Visual references should feel like:

* contemporary architecture studios
* infrastructure organizations
* premium engineering firms
* international professional associations
* modern cultural institutions
* high-end editorial websites

Not:

* startup landing pages
* fintech dashboards
* generic government portals
* construction template websites

---

# 3. Color

Use a restrained palette.

### Primary

**Deep Navy / Institutional Blue**

Used for:

* navigation
* footer
* major backgrounds
* typography
* structural elements

### Neutral

**Warm White / Off White**

Prefer warm white over pure white for large surfaces when appropriate.

### Supporting

**Charcoal / Dark Gray**

For body text and secondary elements.

### Accent

**Indonesian Red**

Use sparingly.

Good uses:

* CTA
* active states
* small highlights
* important numbers
* micro accents

Do not make the entire website red and white.

Indonesian identity should feel **subtle and sophisticated**.

---

# 4. Typography

Typography is one of the primary visual tools.

Use a modern sans-serif with excellent Indonesian character support.

Desired characteristics:

* strong display weight
* clean grotesk feel
* excellent readability
* distinctive but not experimental

### Hierarchy

```text
Display
72–120px

H1
56–80px

H2
40–56px

H3
24–32px

Body
16–18px

Small
12–14px
```

Use responsive `clamp()` values rather than fixed sizes where possible.

### Typography style

Headlines should be:

* short
* bold
* confident
* editorial

Avoid:

* excessive uppercase
* thin giant headlines
* overly decorative fonts
* too many font families

Ideally use **one primary typeface + optional secondary typeface**.

---

# 5. Grid

The grid should feel architectural.

Desktop:

* 12-column grid
* generous outer margins
* consistent gutters
* strong alignment

Mobile:

* simplified column structure
* comfortable horizontal padding
* preserved hierarchy

Elements should align intentionally.

Avoid random positioning.

Asymmetry is welcome **when it still follows the underlying grid**.

---

# 6. Whitespace

Whitespace is a major part of the aesthetic.

Use generous vertical spacing.

Large sections should breathe.

Prefer:

```text
96–160px
```

for major desktop section spacing.

Use smaller spacing on mobile while maintaining the same visual rhythm.

Do not try to fill every empty area.

**Empty space = confidence.**

---

# 7. Layout Style

Favor editorial layouts over component grids.

Good:

```text
Large headline        Large image
Large image            Text
Number + statement     Image
Text                   Image
```

Use:

* full-width sections
* split layouts
* asymmetric compositions
* overlapping elements when tasteful
* large image crops
* horizontal content bands

Avoid:

```text
[Card] [Card] [Card]
[Card] [Card] [Card]
[Card] [Card] [Card]
```

repeated throughout the website.

---

# 8. Photography

Photography should carry a significant portion of the visual identity.

Preferred subjects:

* Indonesian infrastructure
* architecture
* bridges
* roads
* buildings
* construction sites
* engineers
* workers
* urban environments
* industrial details

Photography should feel:

**documentary + cinematic + authentic**

Avoid generic stock imagery.

Avoid cheesy construction imagery such as:

* staged handshakes
* generic hard-hat poses
* obvious stock workers pointing at blueprints

### Image treatment

Prefer:

* large crops
* edge-to-edge images
* strong aspect ratios
* architectural framing
* subtle overlays

Avoid:

* every image inside a rounded card
* tiny thumbnails everywhere
* excessive filters

---

# 9. Cards

Cards are not the primary visual language.

Use cards only when they provide meaningful grouping.

When using cards:

* minimal radius
* subtle border
* little or no shadow
* generous internal spacing
* strong typography

Recommended radius:

**0–12px**

Avoid the modern SaaS convention of:

**24–32px rounded cards everywhere.**

---

# 10. Borders

Prefer borders to shadows.

Use thin structural lines to create hierarchy.

Examples:

```text
1px solid subtle border
```

Useful for:

* navigation
* content separators
* lists
* directory items
* metadata
* cards

The design should feel **solid and architectural**.

---

# 11. Shadows

Use shadows very sparingly.

Avoid:

* floating cards everywhere
* heavy drop shadows
* glowing elements
* excessive depth effects

The interface should feel mostly **flat and physical**, like architecture/editorial design.

---

# 12. Buttons

Buttons should be simple and confident.

### Primary

* solid background
* high contrast
* compact
* medium radius
* strong typography

### Secondary

* outline
* text button
* subtle border

Avoid:

* pill-shaped buttons everywhere
* gradients
* oversized buttons
* excessive button styles

Buttons should look like **navigation controls**, not marketing decorations.

---

# 13. Navigation

Navigation should be minimal and premium.

Use:

* clean horizontal layout
* strong spacing
* clear typography
* subtle active states
* restrained CTA

Avoid overly complex navigation bars.

The header should feel like part of the architecture of the page.

---

# 14. Sections

Each section should have a clear visual identity.

Avoid making every section look identical.

Create rhythm using:

* light background
* dark background
* photography
* typography
* whitespace
* lines
* scale changes

Example rhythm:

```text
LIGHT
Large typography

DARK
Large statistic

IMAGE
Full-width infrastructure

LIGHT
Editorial content

DARK
Institutional statement
```

This creates visual pacing without relying on animation.

---

# 15. Dark Sections

Dark sections should be used strategically.

Good candidates:

* hero
* statistics
* major statement
* CTA
* footer

Dark sections should feel:

**deep + premium + institutional**

not:

**black + neon + futuristic startup.**

---

# 16. Red Accent

Red is a supporting visual accent, not the dominant color.

Use it for:

* small lines
* active states
* CTA details
* numbers
* arrows
* labels
* selected navigation

A little red should be enough to establish Indonesian character.

---

# 17. Motion

Motion should be subtle and purposeful.

Good:

* fade
* slide
* image reveal
* slight transform
* smooth hover
* navigation transitions

Use restrained timing.

Avoid:

* bouncing
* excessive parallax
* constant movement
* flashy transitions
* scroll-jacking

The website should still look excellent with animations disabled.

---

# 18. Iconography

Use icons sparingly.

Preferred:

* simple line icons
* geometric icons
* consistent stroke width

Avoid:

* colorful illustration icons
* emoji-style icons
* excessive icon usage

Typography and photography should do most of the visual communication.

---

# 19. Visual Details

Small details can make the website feel premium:

* thin divider lines
* small uppercase labels
* oversized numbers
* subtle grid lines
* architectural cropping
* precise alignment
* restrained red accents
* editorial metadata
* deliberate whitespace

These details should be subtle.

The design should never feel decorated for decoration's sake.

---

# 20. Responsive Taste

Mobile should preserve the same design personality.

Do not simply stack desktop cards.

Maintain:

* large typography
* strong imagery
* generous spacing
* editorial rhythm
* clear hierarchy

On mobile, simplify rather than shrink.

---

# 21. Design Anti-Patterns

Do NOT use:

* purple/blue SaaS gradients
* glassmorphism
* excessive glass cards
* neumorphism
* giant pill buttons
* excessive rounded corners
* floating blobs
* 3D abstract shapes
* generic AI visuals
* excessive shadows
* rainbow gradients
* dashboard-style homepage
* icon-card overload
* stock-photo grid
* excessive animations

---

# 22. Visual Hierarchy

Every page should have a clear hierarchy:

**1. Statement**

What is the most important thing?

**2. Visual**

What should the user see?

**3. Supporting information**

What explains it?

**4. Action**

What can the user do?

Do not give every element equal visual weight.

---

# 23. Quality Bar

Before considering a page finished, ask:

* Does it feel institutional?
* Does it feel modern?
* Does it feel expensive?
* Does it feel Indonesian without clichés?
* Does it feel connected to architecture/infrastructure?
* Is there enough whitespace?
* Is the typography strong enough?
* Is the grid consistent?
* Is the photography doing enough work?
* Are there unnecessary cards?
* Are there unnecessary decorations?
* Does anything look like a generic template?

If the answer is yes to the last question, redesign that part.

---

# 24. Final Taste

The target visual equation:

```text
60% Institutional
20% Architecture / Infrastructure
10% Editorial
10% Indonesian Character
```

The final impression should be:

> **A sophisticated national Indonesian institution with the visual confidence of a contemporary architecture and infrastructure organization.**

**Design principle:**

> **Less decoration. More hierarchy.
> Less UI. More composition.
> Less noise. More authority.**
